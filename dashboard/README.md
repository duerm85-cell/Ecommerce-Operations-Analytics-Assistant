# Dashboard deliverables

- `interactive_dashboard.html`: dependency-free four-page browser preview with category and channel filters.
- `dashboard_*.png` in `reports/`: high-fidelity static page previews.
- `powerbi_data/`: full generated CSV imports (locally generated and intentionally Git-ignored).
- `dax_measures.md`: tested metric definitions translated to DAX.
- `powerbi_build_guide.md`: shortest path to a genuine PBIX in Power BI Desktop.

No PBIX placeholder is included. A renamed or fabricated file would be misleading and unusable.
