# 电商业务指标字典

本文档统一 Ecommerce Operations Analytics Assistant 的核心业务指标口径。公式中的聚合均受当前分析筛选上下文影响；除非另有说明，金额单位为 TWD。

## GMV

**定义**

商品交易总额（Gross Merchandise Value），表示进入交易流程且未被取消的订单原始交易金额。本项目纳入已完成和已退款订单，排除已取消订单。

**计算公式**

```text
GMV = SUM(orders.gross_amount)
      WHERE orders.status IN ('completed', 'refunded')
```

**业务意义**

GMV 用于衡量平台或店铺的整体交易规模，适合观察业务体量和交易趋势。它不等于最终确认收入，因为尚未扣除折扣，并且包含退款订单，必须结合净销售额、退款状态和毛利共同判断经营质量。

## 净销售额

**定义**

完成订单在折扣后的确认销售金额。本项目只统计 `completed` 状态订单，排除取消和退款订单。

**计算公式**

```text
净销售额 = SUM(orders.net_sales)
           WHERE orders.status = 'completed'
```

**业务意义**

净销售额比 GMV 更接近实际完成交易所贡献的经营收入，是分析品类、商品和客户价值的核心收入指标，也是计算毛利、AOV 等指标的基础。

## 毛利

**定义**

完成订单的净销售额扣除对应商品成本后的金额。

**计算公式**

```text
毛利 = 完成订单净销售额 - SUM(完成订单成本)
```

**业务意义**

毛利用于判断销售增长是否同时创造经营价值。高销售额并不一定代表高质量增长；促销、商品结构或成本变化都可能导致收入增加但毛利不足，因此商品投入和活动决策应同时考虑净销售额与毛利贡献。

## 复购率

**定义**

固定分析窗口内，完成订单不少于两笔的购买用户占全部购买用户的比例。本项目默认窗口为 2025-01-01 至 2025-12-31。

**计算公式**

```text
复购率 = FY2025 内完成订单数 >= 2 的去重用户数
         / FY2025 内至少有 1 笔完成订单的去重用户数
```

**业务意义**

复购率衡量购买用户在指定窗口内再次交易的比例，可用于观察客户留存和持续购买能力。该指标不是严格的同期群留存率，会受到分析窗口长度和用户首次购买时间影响，因此跨周期比较时必须保持窗口定义一致。

## AOV

**定义**

平均订单价值（Average Order Value），表示每笔完成订单平均贡献的净销售额。

**计算公式**

```text
AOV = 完成订单净销售额 / 完成订单去重数
```

**业务意义**

AOV 用于判断客单水平，可以辅助评估定价、商品组合、满额优惠和交叉销售策略。AOV 提升不一定代表利润同步提升，应结合订单量、折扣和毛利观察。

## CTR

**定义**

点击率（Click-Through Rate），表示广告曝光转化为点击的比例。项目使用总点击量除以总曝光量，而不是对每日点击率做简单平均。

**计算公式**

```text
CTR = SUM(clicks) / SUM(impressions)
```

**业务意义**

CTR 反映广告素材、受众定向和投放位置吸引用户点击的能力。较高 CTR 说明广告更容易获得访问，但不能单独证明转化质量或投入产出良好，需要结合 CVR、CPA 和 ROAS 判断。

## CVR

**定义**

转化率（Conversion Rate），表示广告点击进一步形成归因转化的比例。项目使用总转化量除以总点击量。

**计算公式**

```text
CVR = SUM(conversions) / SUM(clicks)
```

**业务意义**

CVR 用于观察点击后的落地页、商品吸引力、价格与购买流程效率。低 CVR 可能说明流量质量或承接环节存在问题，但具体原因仍需结合渠道、活动、商品和用户行为进一步验证。

## CPA

**定义**

单次转化成本（Cost per Acquisition），表示每个广告归因转化平均消耗的广告费用。

**计算公式**

```text
CPA = SUM(ad_spend) / SUM(conversions)
```

**业务意义**

CPA 衡量获取一次转化的成本效率，可用于比较渠道和活动的获客成本。判断 CPA 是否合理时，应与客单价、毛利和客户长期价值结合，不能只选择绝对 CPA 最低的渠道。

## ROAS

**定义**

广告支出回报率（Return on Ad Spend），表示每投入一元广告费获得的归因收入倍数。本项目的分子是广告归因收入，不是订单净销售额或毛利。

**计算公式**

```text
ROAS = SUM(attributed_revenue) / SUM(ad_spend)
```

**业务意义**

ROAS 用于衡量广告预算的收入产出效率，并辅助比较渠道或活动的预算优先级。它不代表利润，也不能直接证明广告带来了等额的因果增量收入；真实预算决策还需要结合毛利、客户增量、归因窗口和实验结果。

## 使用原则

- 比较指标前先确认订单状态、时间窗口、筛选范围和金额单位一致。
- 比率指标使用汇总后的分子除以汇总后的分母，不对明细比率做简单平均。
- 分母为零时应返回空值或受控结果，避免产生误导性的无穷值。
- 广告归因指标用于效率分析，不替代利润分析或因果增量实验。
- 指标定义发生变化时，应同步更新 Python、SQL、DAX、测试和文档；本次文档升级没有改变任何现有指标口径。
