# 数据来源与使用边界

Ecommerce Operations Analytics Assistant 将外部市场信息与内部经营数据分层管理。商品公开数据可以来自合规的外部市场来源；用户、订单和广告数据继续使用业务规则生成的脱敏模拟数据。

## 数据流程

```text
真实公开商品数据
        ↓
crawler/raw_data/raw_products.csv（ODS）
        ↓
字段映射、类型清洗、去重、质量校验、业务品类映射
        ↓
业务模拟数据生成（users / orders / ads）
        ↓
Python / SQL / DAX 指标计算与对账
        ↓
Power BI 决策看板
```

## External Market Data

External Market Data 指可以合法访问和使用的真实公开商品市场数据，用于补充商品主数据中的市场属性：

| 字段 | 含义 | 质量要求 |
|---|---|---|
| `product_id` | 来源商品唯一标识 | 非空、唯一 |
| `product_name` | 公开商品名称 | 非空 |
| `category` | 来源商品类别 | 非空，并可映射至项目业务品类 |
| `price` | 商品公开价格 | 大于 0，进入分析层前统一为 TWD |
| `rating` | 商品公开评分 | 大于 0 且不超过 5 |
| `review_count` | 公开评价数量 | 非负整数 |

### 来源优先级

1. 许可证允许当前用途的 Kaggle 公开电商数据集。
2. 政府、研究机构、开源社区或数据提供方发布的公开商品数据集。
3. 无需登录、无需绕过访问控制，且服务条款与 `robots.txt` 允许访问的公开网页或接口。

项目不使用登录态、Cookie、验证码破解、代理轮换、浏览器指纹伪装或复杂反爬绕过。具体数据集在使用前必须确认许可证、来源页面、采集日期、币种和可再分发范围。

### ODS 与清洗规则

`crawler/raw_data/raw_products.csv` 是商品 ODS 输入。`crawler/product_crawler.py` 将不同公开数据集的列名映射到统一六字段合同，并执行数值清洗、去重和基础范围校验。

进入分析层时，`data/generate_data.py` 会再次检查字段完整性、主键、价格、评分、评价数及业务品类。原始来源品类保留在 ODS；分析层品类映射到项目既有的六类商品体系，以保证订单成本和 Power BI 分类口径兼容。无法可靠映射的品类会停止处理，不会被静默归入错误类别。

外部来源没有 `sold_count`、店铺、地区等项目内部字段时，这些字段继续由原固定种子商品框架提供，仅作为模拟业务属性，不得解释为真实市场销量或真实商家信息。

## Internal Business Data

以下数据继续由项目中的固定随机种子和业务规则模拟生成：

- `users`：注册日期、地区、获客渠道和复购倾向等客户分析字段。
- `orders`：订单日期、数量、金额、折扣、成本和订单状态。
- `ads`：曝光、点击、花费、转化和归因收入。

这些内部数据用于验证客户价值、订单经营和广告效率分析链路，不代表任何真实企业、平台、店铺或个人。

## 为什么内部经营数据使用模拟数据

真实用户、订单和广告数据通常包含个人信息、交易金额、客户行为、渠道策略、预算与企业经营结果，受到隐私法规、企业安全制度和保密协议约束，不适合直接进入公开仓库。

本项目通过脱敏模拟数据验证数据模型、ETL、指标口径、SQL/Python/DAX 对账、数据质量检查和 Power BI 交付能力。模拟数据产生的业务结论只用于验证分析方法，不能被解释为真实市场表现。

## 输入优先级与回退

商品数据流程遵循以下规则：

1. `raw_products.csv` 存在、包含数据且通过校验时，优先使用外部商品属性。
2. 文件不存在或只有表头时，继续使用原固定种子商品生成逻辑。
3. 文件存在但字段错误、数据非法或品类无法映射时，流程明确失败并报告原因，避免静默污染分析结果。

仓库当前提交的是表头模板，因此默认 pipeline 和已验证的 Power BI V1.2 结果保持不变。填入真实商品数据后，建议先将 `--output`、`--samples` 和 `--powerbi` 指向临时目录完成核验；只有在确认币种、品类映射和 KPI 影响后，才刷新正式 Power BI 数据输入。

## Power BI 边界

- 本阶段不修改 PBIX、PBIP、PBIR、TMDL 或 DAX。
- 现有 V1.2 PBIX 继续保留原验证数据与 KPI。
- 外部商品数据只在明确填充 ODS 并重新运行数据生成时影响新的下游数据文件。
- 将外部商品价格用于经营指标前，必须确认币种转换、商品覆盖率和订单模拟适配结果。
