# Portfolio pitch

## 60-second introduction

I built a platform-neutral e-commerce operations analytics system using Taiwan women's consumer goods as the case setting. I created a compliance-first product collector framework and a fixed-seed dataset covering products, 60,000 orders, 12,000 users and daily advertising. I modeled the data for MySQL, wrote business SQL with CTEs and window functions, and reconciled core metrics against Python and a local SQLite validation layer. The final deliverables include product, sales, customer and advertising analyses, transparent Hot and Opportunity scores, RFM segments, four dashboard pages and a browser demo. The emphasis is decision quality: every finding states the fact, a plausible cause, an action and the metric that would validate it. All synthetic-data and Power BI limitations are explicit.

## Resume-ready bullets

- Built a reproducible e-commerce analytics pipeline spanning compliance-first data acquisition, fixed-seed generation of 60K orders/12K users, MySQL 8 modeling, SQL/Python analysis and four decision-focused dashboard pages.
- Standardized GMV, net sales, gross margin, AOV, repeat rate, RFM, CTR, CVR, CPA and ROAS; reconciled seven core KPIs across SQLite SQL, pandas and dashboard outputs with automated data-quality tests.
- Designed transparent Hot and Opportunity scoring plus actionable product/customer/ad diagnostics, converting findings into margin, retention and budget experiments with explicit validation metrics and limitations.
